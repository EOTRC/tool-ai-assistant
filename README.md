# Tool

Tool — мой личный локальный ИИ-ассистент для терминала. Собрал его для себя,
потому что надоело переключаться между окнами: всё — чат с моделью, работа с
файлами, поиск по своим документам — теперь живёт в одной консоли.

Весь код этого проекта написан ИИ. Я собирал его как конструктор под свои
задачи: что-то генерировал, что-то правил, что-то переделывал. Если найдешь
странности в коде — они честные, как были написаны.

Билд я делаю ещё и для друга, поэтому проект лежит на GitHub: отсюда удобно
скачивать готовые бинари для Windows, Linux и macOS (включая M1/M2/M3).

## Что умеет

- `chat` — диалог с локальной моделью прямо в терминале (`exit` / `пока` — выход)
- `ask`, `ask-file`, `code`, `summarize`, `translate` — вопросы и задачи по файлам
- `index` / `search` — поиск по своим документам через эмбеддинги (RAG)
- `clip` — взять текст из буфера обмена и сделать с ним что попросишь
- `screen` — скриншот экрана и описание через vision-модель
- `web` — поиск в интернете
- `shell` — сказать по-русски, какую команду выполнить, и получить её
- `selftest` — самодиагностика, чтобы убедиться, что всё работает
- `install` — поставить все нужные ИИ-модели одной командой

Работает с [Ollama](https://ollama.com) полностью локально — наружу ничего не
уходит, кроме запросов в интернет, если сам попросишь поискать.

## Установка на macOS

Скачай из релиза три файла и положи в одну папку: `tool`, `toolcmd` и
`install_mac.sh`. Затем в терминале:

```sh
bash install_mac.sh
```

Скрипт сделает всё сам:

- снимет карантин Gatekeeper — macOS ругается на каждый скачанный файл без
  подписи Apple, а платить за подпись я не стал;
- сделает бинари исполняемыми и положит их в `~/.local/tool`;
- добавит `~/.local/tool` в PATH — после этого `tool` и `toolcmd` работают
  из любого места в терминале;
- проверит Ollama, установит, если нужно, и предложит поставить модели.

После установки открой новый терминал (или `source ~/.zshrc`) — можно
пользоваться.

## Установка моделей

Все модели, которые используются в коде, ставятся одной командой:

```sh
tool install
```

По умолчанию это:

- `qwen3:1.7b` — основная модель (чат, файлы, переводы)
- `qwen2.5-coder:7b` — работа с кодом
- `qwen2.5vl:3b` — картинки и скриншоты
- `nomic-embed-text` — эмбеддинги для поиска по документам

## Windows и Linux

Ничего устанавливать не нужно: скачай бинарь под свою систему из релиза и
запускай. Настройки лежат в `settings.cfg` рядом с исполняемым файлом.

## Как пользоваться

```sh
tool chat                              # диалог с ИИ
tool ask-file отчет.docx сделай резюме
tool index ~/documents                 # построить поиск по папке
tool screen "что на экране?"           # скриншот + описание
toolcmd                                # консоль: команды Tool без префикса
```

Настройки моделей, устройства (cpu/gpu), язык ответов — всё в `settings.cfg`.
Шаблон — `settings.cfg.template`, он лежит в репозитории и в релизе.

## Заметки

- На macOS бинари не подписаны (у меня нет платного аккаунта Apple Developer),
  поэтому первое предупреждение macOS — норма. `install_mac.sh` снимает его
  автоматически.
- Это мой личный инструмент, собранный с ИИ. Код открыт (MIT) — бери, правь,
  делай под себя.
